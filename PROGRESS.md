# Progress

- Button — 3 orthogonal axes: `color` (8: primary/secondary/success/info/warning/danger/light/dark), `variant` (solid/outline/ghost/link), `shape` (rounded/square/pill) + `size` (sm/md/lg/icon); `asChild` via Radix Slot, `loading` (disables + centered spinner, width preserved). Colors via token CSS-var indirection (`--btn-color`/`--btn-on`); intent tokens recolored to Bootstrap palette (oklch), same in light/dark. typecheck/lint/build/build-storybook green; `"use client"` preserved in dist.
- IconButton — icon-only button built on `Button`; requires `aria-label` (enforced at the type level), inherits `color`/`variant`/`shape`/`loading`/`asChild`, adds own square `size` (`sm`/`md`/`lg` → `size-8`/`9`/`10`) matching Button heights. Exports `IconButton`, `iconButtonVariants`, `IconButtonProps`. typecheck/lint/build/build-storybook green; `"use client"` preserved in dist.
- Input — tokens-only, data-agnostic `<input>`; forwards all native props (`value`/`onChange`/`type`/`placeholder`/`name`/`aria-invalid`). Adds `size` (`sm`/`md`/`lg` → `h-8`/`9`/`10`, heights match Button), native `disabled`, and an `aria-invalid` error state (attribute-driven so look matches a11y semantics). Bootstrap-style focus: soft 4px ring at 25% opacity hugging the border (no offset) + matching border, both via a dedicated `--input-ring` token (defaults to `--primary`, host-overridable without touching the button/primary color); swaps to `--destructive` when invalid. `forwardRef` onto the DOM node. Exports `Input`, `inputVariants`, `InputProps`. typecheck/lint/build/build-storybook green; `"use client"` preserved in dist.
- Textarea — tokens-only, data-agnostic `<textarea>` mirroring Input's contract; forwards all native props (`value`/`defaultValue`/`onChange`/`rows`/`placeholder`/`name`/`aria-invalid`). Native `disabled`, attribute-driven `aria-invalid` error state (destructive border + ring), and an optional `autoResize` prop that grows to fit content via `scrollHeight` (all-browser; sets `resize-none overflow-hidden`). `forwardRef` exposes the DOM node through `useImperativeHandle` so auto-resize can read `scrollHeight`. Exports `Textarea`, `textareaVariants`, `TextareaProps`. typecheck/lint/build/build-storybook green; `"use client"` preserved in dist.
- Label — accessible form label built on Radix Label (unified `radix-ui`); associates with a control via `htmlFor` and forwards clicks to it. Tokens-only + dark mode; dims with its field via `peer-disabled` (sibling control) and `group-data-[disabled=true]` (ancestor-marked) paths. No variants. `forwardRef` onto the DOM node. Exports `Label`, `LabelProps`. typecheck/lint/build green; `"use client"` preserved in dist.
- Storybook docs convention — global autodocs + react-docgen-typescript; fixed Docs-page layout (intro+Usage → live Default+controls → props table → example stories; shown code = real usage). Codified in AGENTS.md; Button stories follow it. typecheck/lint/build/build-storybook green.
- Theming & branding — full palette aligned to **Bootstrap 5.3**: neutral surfaces (bg/fg/card/popover/muted/accent/border/input/ring) recolored to BS gray scale in light+dark (intents already BS). Tier-1 token API (the branding surface) expanded with `--font-mono`, `--chart-1..5`, sidebar tokens (`--sidebar*`; brand slots chain to `--primary`/`--ring`), and a BS-ordered z-index scale (`--z-dropdown`…`--z-toast`); chart/sidebar/z-index seeded ahead of their components. Textarea focus aligned to Input's `--input-ring` glow (one brand override drives both fields). AGENTS.md gains a "Theming & branding" section: source-separation rule (colors from Bootstrap 5.3, behavior/a11y from shadcn/Radix), 3-tier token model, tokenization policy + litmus test, consumer branding workflow. `@theme inline` mapping extended (chart/sidebar/font-mono). Additive; component APIs unchanged. typecheck/lint/build/build-storybook green; `"use client"` preserved in dist.
